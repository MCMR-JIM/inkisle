# 分类工具栏、线类端点编辑与旋转

## 已确认的产品方向

本次为现有白板增加分类工具入口、双向箭头、三种多边形、端点编辑和单对象旋转。沿用原生 TypeScript、自研 Canvas、零运行时依赖，以及淡蓝柔光选中效果。

### 工具栏

- 一级入口：选择、抓手、画笔、图形、直线、文字、便签、图片、橡皮。
- 分类按钮的名称固定为“图形”“直线”，不随子工具改变。分类按钮显示稳定的分类图标，不显示下方小箭头；当前工具由分类/子面板选中态表达。主工具与子工具的已配置快捷键常态显示。
- 点击分类按钮打开居中排列于主工具栏下方的单行横条子面板；选择子工具后激活工具并保持横条可用，点击外部不关闭；再次点击已打开的分类按钮关闭。
- 图形子工具：矩形、椭圆、菱形、三角形、五边形、六边形。
- 直线子工具：直线、箭头、双向箭头。
- 按 Esc、切换独立工具可收起横条，切换分类时更换横条内容。当前子工具在面板中明确高亮；两层工具栏共用中心线并上移，以减少对画布的占用。
- 保留已有快捷键，不为新增多边形强行分配冲突快捷键。
- 主工具栏顶部为桌面 64px、中屏 62px、小屏 58px；子工具仍保持 6px 间距并共用中心线。新建画板加号放在右上角主题切换按钮左侧，使用无额外描边的图标按钮；窄屏下标题可收缩，顶部按钮不换行或溢出。

### 选择与端点编辑

- 单选直线、箭头、双向箭头：显示两个圆形端点控制点，不显示四角矩形缩放手柄；保留淡蓝柔光。
- 拖动一个端点时，另一端的世界坐标不变；拖线身仍整体平移。端点可跨过另一端，不因方向反转而交换起终点语义。
- 按住 Shift 拖动端点时，以固定端点为锚，将线方向吸附到 45°，与现有绘制约束一致。
- 箭头绑定终点，双向箭头绑定两端；端点编辑和旋转后重新计算箭头头部的方向。
- 被橡皮切断的直线类片段保留可识别的端点语义。片段继承仍完整存在的箭头端，新的切口不生成箭头。箭头头部部分被擦除时保留实际几何残片，不凭空补全；不具备完整线类语义的残片保持自由路径。
- 普通图形及一般自由路径显示淡蓝虚线矩形及位于该框四角的缩放手柄，框、点、命中与缩放共用同一几何；单对象时整体跟随对象旋转。手绘曲线、切开的图形轮廓等不因“开放路径”就误识别为直线。
- 多选继续使用整体包围盒缩放，不显示多个对象各自的端点控制点。
- 框选只选择完全位于选框内部的对象世界边界；边界相交或只覆盖对象大部分均不选。单击选择继续使用精确对象命中逻辑。白板工具 UI 禁止原生文本选择，复制无选中对象时清除 DOM 选区；输入框、文字编辑器与 HEX 仍允许正常文字选择。

### 旋转

- 单选普通图形、自由路径、文字、便签或图片时，从选框顶部中心向外伸出旋转手柄，拖动绕对象中心旋转。
- 单选直线类时，从线段中点沿垂线方向伸出旋转手柄，拖动绕线段中点旋转。手柄到线/对象边缘的距离以屏幕像素保持稳定，缩放视口后仍易于操作。
- 默认自由旋转；按住 Shift 将对象的最终角度吸附到 15° 的整数倍。
- 旋转手柄、连接杆和端点沿用低调蓝色；保留对象原色，不新增实体选中描边。
- 锁定对象不显示编辑手柄，不能通过端点、缩放或旋转改变。
- 多选旋转在本轮不增加，后续可按整体包围盒中心实现；本轮多选不显示旋转手柄，以免产生无效入口。

## 技术方案与取舍

### 统一对象变换，而非把所有对象烘焙为路径

保留参数化图形，增加可选 `rotation` 字段，默认为 0 弧度；旋转中心采用对象未旋转的逻辑包围盒中心。比直接改写所有顶点更能保留矩形圆角、文字、便签和图片的原始编辑能力，也避免每次旋转重写大量笔迹样本。

直线类的端点坐标仍由起点和向量表示。端点编辑或旋转后可规范化为世界空间两端坐标并保持线类旋转字段为 0，从而避免端点语义与对象角度重复叠加。箭头两端的头部状态由明确元数据表示；工具和持久化类型必须覆盖双向箭头。

### 核心接口边界

- `core/model.ts`：新增图形/双向箭头类型、可选对象旋转、直线片段语义。旧文档缺失新增字段时仍能读取。
- `core/transforms.ts`：对象局部/世界坐标转换、旋转中心、角度规范化、Shift 角度吸附、旋转后边界。
- `core/linear.ts`：线类识别、世界空间两端读取、固定另一端的端点编辑、箭头头部状态。几何残片不凭外观推断类型。
- `core/paths.ts`：矩形、椭圆、菱形、三角形、五边形、六边形的共享几何，以及双向箭头的原始路径。
- `engine/renderer.ts`：旋转后的手柄位置、端点命中、旋转命中与预览；光晕仍基于真实绘制像素。
- `engine/interaction.ts`：独立端点/旋转手势，实时预览，松手一次历史提交；Esc、失焦或指针取消恢复原状。
- `ui/tool-families.ts`：分类和子工具元数据，浮动面板的打开/关闭、键盘与焦点逻辑；工具栏不引入第三方组件。

### 绘制、几何和存储的一致性

- Canvas 绘制、命中检测、空间索引、柔光、选中手柄、PNG、SVG、缩略图必须采用相同旋转变换。
- 精确命中先把指针逆变换回对象局部坐标；空间索引记录旋转后的世界轴对齐包围盒。
- 擦除采样先逆变换进对象坐标；圆形橡皮在旋转变换下仍保持正确半径。裁切输出片段须继承原对象变换或在世界空间重定位，不能因归一化片段边界改变旋转中心而发生跳动。
- 对旋转对象的缩放在对象局部轴中执行；调整局部几何/尺寸后同步计算中心与世界位置，保持对角锚点稳定。多选缩放沿现有世界轴整体缩放规则处理，验证旋转对象无错误位移。
- 文件校验接受缺省旋转，拒绝非有限角度和非法新增路径数据。源文件、本地增量日志、Worker 与导出全部保留新增语义。
- 单次端点拖动或旋转只提交一次事务；无实际移动的手柄点击不增加撤销步骤。渲染仍只经过一个 RAF，不在每个 pointermove 保存。

## 验收与测试

### 核心

- 拖起点/终点时另一端不动，支持负向线、水平、垂直及越过固定端点。
- Shift 端点 45° 吸附；Shift 旋转最终角度 15° 吸附；跨越 -π/π 时旋转连续。
- 新图形多边形顶点数、边界、命中和文件往返；双向箭头两端头部方向正确。
- 旋转后的命中、空间索引、局部擦除及切断后片段位置正确。
- 被擦断的普通线、单向/双向箭头保留正确端点和箭头语义；部分头部损坏不被重建。
- 撤销/重做恢复对象几何、角度和片段语义，旧文档仍可读取。

### 真实浏览器

- 分类按钮点击、子面板六种图形/三种直线选择、键盘与点击外部关闭、小屏和明暗主题。
- 单选线只出现两个端点和旋转手柄，拖线身平移；普通图形显示四角缩放与顶部旋转手柄。
- 真实鼠标编辑两端、旋转图形/箭头、按 Shift 吸附、Esc 取消、锁定与撤销重做。
- 旋转后再次缩放、端点编辑、擦除、复制、刷新恢复、源文件导入导出及 PNG/SVG 一致。
- 性能检查：拖动期间只刷新必要画布层，无新增永久动画循环或生产依赖。

## 文档自查

分类名称采用用户明确指定的固定“图形”“直线”；子面板包含新增三种多边形。端点编辑和旋转使用不同的 Shift 吸附步长，已经明确。单选旋转覆盖所有可选对象；多选旋转明确留给后续，界面不显示无效手柄。本文件待用户审阅后进入实施计划。
