# 压感与鼠标速度笔迹

## 已确认的体验

- 画笔默认开启压感，设置中提供开关；关闭后画等宽线。
- 手写笔使用 Pointer Events 真实压力，轻压细、重压粗，平滑变化。
- 鼠标使用速度模拟：慢画稍粗、快画稍细；使用屏幕 CSS px / ms，避免受视图缩放影响。普通触摸维持等宽。
- 预览、提交、保存恢复、复制、撤销重做、擦除和 PNG / SVG 导出保持相同的宽度变化。
- 保持现有 1%–2000% 缩放范围、零运行时依赖和中文界面。

## 技术决策

逐段改变 Canvas lineWidth 实现简单，但交接处容易出现接缝和半透明叠色。将笔迹永久转为轮廓会丢失压力采样及后续线宽编辑能力。采用保留中心线与压力、生成统一填充几何的方式：连续圆形笔尖与连接四边形组成同向复合路径，一次填充，画布与 SVG 共用。

新增纯 TypeScript 压力输入模块，负责设备分流、速度映射和时间相关平滑。笔迹几何模块负责中心线二次曲线离散、压力插值、变宽轮廓、虚线分段和命中。绘制预览保持每帧最多一次绘制；完成笔迹缓存几何。

新笔迹显式存储可选 pressureEnabled 布尔标记；缺少标记的旧文件保持旧等宽外观。每个点继续使用现有 pressure 数值。擦断后的开放路径继承变宽标记，并在切点插值压力；局部坐标转换与缩放保留压力。文件校验新增标记及路径采样压力校验，版本保持 1。

压力为 0 时不以 truthy fallback 改写为 0.5。鼠标默认中等粗细，速度映射有上下限，时间戳重复或逆序不造成无限速度或 NaN。抬笔事件的硬件零压力不强制使最后一段突然收尖，保留最后接触压力；实际接触过程中压力下降可自然收笔。压感感知简化保留沿直线变化的压力峰谷，防止松手后粗细消失。

线宽为最大笔尖直径，实际直径在该值的 25%–100% 之间。普通边界按最大线宽保守包围；精确命中按实际变宽中心线计算。虚线使用原有 8 / 6 世界坐标节奏，Canvas 和 SVG 同步。

设置开关沿用现有样式面板，默认开启并记住设备偏好。选中画笔时可切换已有笔迹的压感并支持撤销。图形、识别、文字、橡皮维持原有交互。

## 验收

1. 相同轨迹不同手写笔压力产生不同宽度，直线压力峰谷在提交后保留。
2. 同样距离鼠标慢画比快画粗；不同缩放下同样屏幕速度得出一致模拟压力。
3. 零压力、重复时间戳、单点、重复坐标、快速回转与半透明交叠均保持合法几何。
4. 旧等宽文档外观兼容；新标记与压力正确往返，非法标记和压力被拒绝。
5. 擦断后片段仍具有原位置的粗细，切点压力正确，移动、旋转、缩放和反复擦除不丢失压力。
6. 浏览器像素测量验证变宽预览与完成一致、SVG 和 PNG 外观一致、关闭后等宽、偏好恢复及撤销重做。
7. 运行单元测试、功能浏览器测试、生产构建和生产浏览器测试，检查长压感笔迹绘制耗时。
