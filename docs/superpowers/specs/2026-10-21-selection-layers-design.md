# 选取保持层级与逐层移动

## 用户要求

- 选中对象时，内容和高亮仍处于对象自己的图层，不会看起来自动置顶。
- 移动、缩放和旋转预览也遵守同样的前后遮挡，透明上层对象只合成一次。
- 保留置于顶层/底层，增加上移一层/下移一层；支持单选和多选，保持组内顺序。

## 技术方案

原问题来自交互 Canvas 的选中高亮辅助器重新绘制全部选中对象，使下层原像素盖住上层。高亮辅助器改为只提供柔光；Renderer 按场景精确顺序依次绘制柔光、选中内容和其上的对象。选取/编辑期间交互层使用不透明背景完整合成可见视口，避免上层半透明像素在静态层和交互层叠加两次。编辑预览按 ID 替换原对象位置，包含从离屏拖入的对象。

图层操作抽成纯函数 `layerChanges`，以 `compareElements` 排序，单步交换相邻选择区段与未选中对象；置顶置底稳定分区。通过交换现有精确 order/orderPath 排名实现，不使用大时间戳上的浮点中间值。重复旧层序只在真正移动时规范化；边界操作不产生历史。锁定对象不作为可移动选择项。

左侧分两排显示图层和对象操作，图层四按钮为置底、下移一层、上移一层、置顶，不增加额外边框。右键菜单同步提供四项。逐层操作默认 `Ctrl [` / `Ctrl ]`（macOS Command），原 `[` / `]` 置底置顶保留；均进入可编辑键位列表，悬浮提示与菜单提示同步。

## 验收

真实像素验证选取和拖动下层对象的遮挡、不透明和半透明上层、擦除孔洞与非连续多选；验证多选稳定排序、嵌套拆分 rank、锁定/边界、一次撤销和刷新/文件往返。运行单元、浏览器功能/性能和生产测试，并检查窄屏布局。
