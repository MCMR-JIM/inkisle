# 颜色快捷键、调色板与暗色界面

## 目标

- 在白板主界面拦截 Tab：按预设色顺序切换下一个描边色；Shift+Tab 切换上一个，首尾循环。选中对象沿用修改样式和撤销逻辑；无选中对象则影响之后绘制。填充不受影响。
- 输入框、文字编辑、调色板与模态弹窗保留原有键盘操作。Ctrl / Alt / Meta + Tab 不作为颜色快捷键。
- 描边和填充各 10 色，预设色使用每行 5 个圆角正方形；填充预设全部为普通颜色，标题旁的填充开关控制透明/选中色。各自标题边提供调色板按钮。
- 调色板使用自研 HSV 饱和度/明度二维色盘、色相滑条、上下原色/新色对比和等高 HEX 输入，不调用系统颜色选择窗口。选中预设时编辑器与该位置实时绑定，两处色块同步预览；切换预设或完成/关闭时一次提交，取消回退当前项。HEX 有效值立即预览，失焦先应用合法值后规范回填，非法/空值恢复最近有效色号。
- 描边与填充调色板左侧紧贴样式面板右侧、顶部与样式面板顶部对齐。窗口调整时保持停靠，小屏按剩余宽度收窄，短屏限制高度并内部滚动。
- 暗色界面统一继承主题前景色，菜单、子工具、按钮、文本输入和提示使用相应文字色；画板内容本身的颜色不改写。
- 移除顶部工具搜索、命令弹窗、Ctrl K 应用快捷键与无用逻辑，帮助和 README 同步。
- 键位列表中加入颜色快捷键；点击键位后录入新组合键，检测冲突并支持清除、取消、恢复默认。应用动作共用可持久化映射，工具栏提示同步更新；固定平移/编辑手势和系统剪贴板组合键列为说明。刷新保留用户改绑，包括互换工具键位。
- 描边和填充的十个预设色独立可连续编辑。浮窗中点选预设或双击主面板色块选择要修改的位置；切换色块保存上一项，取消保留已经切换保存的项并回退当前项。移除“仅应用当前颜色”与常驻操作说明，解释统一放入不受浮窗裁剪的悬浮气泡。“恢复预设”重置当前组；填充关闭时选色不自动开启，两组配置分别持久化在本机，校验失败恢复默认，不修改已有文档中其他对象的颜色，描边快捷键消费最新预设。
- HEX 右侧吸管进入画布取色，使用自研方形像素放大镜，下方实时显示 `#rrggbb`。按当前屏幕/DPR 采样主画布与交互层合成像素，浮动界面区域不采样。点击或 Enter 将颜色带回草稿，Esc / 右键取消，期间拦截绘制和底层快捷键。系统屏幕取色入口及其浏览器 EyeDropper 调用已移除，画布取色不依赖该接口。关闭调色板会终止取色并忽略过期结果。
- 普通按钮在指针点击后释放焦点，不通过 Space / Enter 自动重复激活；键位录入和展开的组合选择器保留专用键盘操作。点击画布时显式恢复画布焦点，空格始终作为主界面的临时平移键；文字输入、调色板、弹窗保持自己的空格操作。鼠标选择字号后关闭选择器并释放焦点，键盘选择则保留其焦点。

## 验证

浏览器测试覆盖描边双向循环、填充不变、选中/锁定对象和撤销、自定义色确认/取消/保存、输入焦点例外、桌面和移动端正方形网格、两套调色板、暗色按钮与菜单的计算对比度及搜索移除。保持现有绘制、压感和生产构建测试。
