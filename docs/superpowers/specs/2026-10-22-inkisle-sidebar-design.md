# 墨屿 · InkIsle 改名与侧栏居中

用户选择新产品名 **墨屿 · InkIsle**、项目标识 `inkisle`、源文件后缀 `.inkisle`。本轮只改源码和测试；`release/` 的既有留白 Windows 发行目录、ZIP、manifest 和验证记录保持原样，不运行原生打包命令。

## 侧栏

根因是 `.properties` 与收起后的展开按钮使用固定顶部像素。改为以窗口垂直中点定位；内容因压感/选择操作增减后仍居中。顶部保留工具栏安全区、底部保留历史/缩放控制区；矮窗口里限制侧栏最大高度，内部滚动。调色浮窗继续紧贴侧栏右边、顶边对齐，并观察侧栏实际尺寸变化，避免新增选择操作后停留在旧位置。字号下拉保持独立定位。

## 名称与兼容

前端集中定义产品显示名、英文名、文件后缀和旧后缀。更新网页标题、Logo 旁文字、空状态、帮助、导出菜单、文件选择器、拖放、错误提示、package/lock、README，以及未来 Windows 构建的 EXE/包名/窗口文案。

新导出使用 `.inkisle`，导入同时接受 `.inkisle` 和 `.liubai`，扩展名判断忽略大小写；仍严格校验文件内容。二进制容器版本、校验和和已有 `LWB1` 文件头保持兼容，不因营销改名重写文件格式或废弃旧文件。

现有 IndexedDB 名、偏好存储键、桌面本地 origin 和用户数据目录属于持久兼容标识，保留为明确记录的旧标识，避免更新后看似丢失画板或设置。新的公开诊断接口为 `window.inkisle`，兼容 `window.liubai`；桌面消息协议继续保留既有通道。新复制内容采用 `inkisle-elements`，粘贴也接受旧 `liubai-elements`。

保留既有绿色视觉与 Logo 几何；本次不重新设计标志、不创建 GitHub 仓库、不提交或推送。GitHub 仓库建议名 `inkisle`，名称是否独占不作保证。

## 验收

- 多窗口尺寸、选择/未选择/压感/收起展开状态均居中或在安全区内滚动，不遮住顶部/底部控制。
- 调色板在侧栏位置变化后仍贴边；明暗主题与移动端可操作。
- `.inkisle` 导出往返、旧 `.liubai` 导入和拖入、大小写后缀、旧数据库与设置恢复、旧剪贴板均通过。
- Web 构建/单元/浏览器回归通过；本轮不执行 `package:win*` 或 `test:windows`，也不写入 `release/`。
- 已有 ZIP SHA-256：lite `d6c70b5706d9b8b48c6b817bbd7a8a55d0ba2336adcee749a6f2fa8b9175cdee`；offline `8a8d1540c55d906795120f00a850b2b8ffcc69dfb8e952d424211988cafb19a8`。
