# 留白：轻量本地白板

## 目标与取舍
从空目录实现浏览器端可用的白板。原生 TypeScript、CSS、Canvas 2D、IndexedDB，无生产依赖。选择 Canvas 2D 而非 WebGL 是为了小体积、成熟文字渲染和较低实现复杂度；使用分层与空间索引改善性能，而非提前引入 GPU 引擎。浏览器文件系统、输入、编码和数据库 API 是必要基础。

## 产品与视觉
温暖的灰白画布、细点网格、森林绿强调色、浮动工具条与克制的圆角。中文界面；所有图标自绘 SVG。提供可编辑的初始示例和空白新建入口。用户可通过空格/中键平移、滚轮与触控板缩放或平移。

## 首版能力
- 笔迹、矩形、椭圆、菱形、箭头、线条、文字、便签、图片。
- 框选、多选、移动、缩放、删除、复制粘贴、层级、锁定、快捷键。
- 撤销重做，以一次手势为一次历史记录。
- 多画板、自动保存、改名、自研文件导入导出、PNG/SVG 导出。
- 深浅主题、网格切换、快捷键帮助与命令搜索。

## 内核边界
- `core/model.ts`：元素、视口、文档类型和工厂。
- `core/geometry.ts`：边界、坐标变换、精确命中、笔迹简化。
- `core/spatial.ts`：自研均匀网格索引；超大元素单独维护。
- `core/scene.ts`：有序场景、索引更新、命令历史和变更通知。
- `core/codec.ts`：版本化二进制文件头、UTF-8 数据与 CRC32 校验，输入验证。
- `storage/repository.ts`：IndexedDB 原子事务，增量日志、快照、恢复与画板元数据。
- `storage/snapshot.ts`、`snapshot.worker.ts`：大文档后台校验与编解码；小文档避免 Worker 冷启动成本。
- `engine/renderer.ts`：静态场景层与交互层、DPR、视口裁剪、按需帧调度。
- `engine/interaction.ts`：Pointer Events、手势状态机、合并事件、文字编辑定位。
- `ui/*`：轻量 DOM 界面与快捷操作；界面更新不进入笔迹采样热路径。

## 保存与错误处理
每个已完成的操作产生 upsert/delete 补丁，异步顺序写入日志；累计 64 个写入批次后原子更新快照并删除已覆盖日志。元数据、快照、日志分表，普通保存不读写快照。加载时恢复快照及后续日志。仅事务完成后显示已保存。失败保留待写队列、显示可重试状态，并可导出。版本比较防止其他窗口或快照编码期间的提交被覆盖。文件读取先校验长度、版本、校验和及结构，再替换场景。页面隐藏时尽快刷新待写操作；关闭窗口前有未落盘操作则请求浏览器提醒。

## 性能与验证
不使用绘图框架、状态管理库、图标库或运行时前端框架。活动手势在预览层绘制，静态层只在场景/视口变化后刷新。空间索引避免遍历离屏对象；不运行永久动画循环。目标生产 JS gzip 小于 70 KB。以浏览器本机测量启动、5000 元素场景帧耗时及持久化耗时并报告实际数据；不将软件帧耗时等同于硬件端到端输入延迟。核心测试覆盖几何、索引、撤销重做、文件损坏和增量恢复；浏览器测试覆盖真实绘制、编辑、刷新恢复、导入导出和快捷操作。
