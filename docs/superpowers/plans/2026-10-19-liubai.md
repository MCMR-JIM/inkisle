# 留白 Implementation Plan

**Goal:** 从零交付可运行、无生产依赖、数据本地保存的高性能白板。

**Architecture:** TypeScript 模块化内核；双 Canvas 按需渲染；IndexedDB 自研增量仓库；原生 DOM 组件。按内核、存储、交互界面、端到端验证顺序在当前会话实现。

**Tech Stack:** TypeScript 5.9、Canvas 2D、IndexedDB；Vite、Vitest、Playwright 仅开发使用。

## Global Constraints
- 所有工程文件在当前目录内。
- 零生产依赖，不使用白板、Canvas、状态管理或 UI 框架。
- 一次操作一个历史事务；持久化必须在真实写入成功后更新状态。
- 中文 UI、键盘可达工具、减少动画支持；响应式适配小屏。
