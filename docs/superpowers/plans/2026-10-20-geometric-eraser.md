# 几何橡皮与独立片段

用户已确认：笔迹和线条按剩余连续片段拆分；无填充图形转为开放路径；填充图形求差集并按连通分量拆分；文字、便签和图片保留局部蒙版。

## 数据与内核
- 新增内部 `path` 元素，保存局部填充环（even-odd，含孔洞）和独立描边路径。绘制工具不增加额外入口。
- `core/paths.ts` 将矩形圆角、椭圆、菱形、箭头、平滑笔迹离散为有误差上限的矢量折线；不光栅化文档。
- `core/clip.ts` 在线段参数域内裁切圆/椭圆扫掠区域，插值交点。
- `core/boolean.ts` 对主体边界和橡皮胶囊边界建立局部平面分割，抽取差集边界及孔洞，按包含关系分组；不在切口上重画原图形描边。
- `core/cut.ts` 将结果归一化为独立对象，保持颜色、线宽、透明度和层级；箭头保持实际残余头部，不为新端点生成箭头。

## 接入
- 实时输入仍更新局部蒙版；松手生成一个替换原对象并插入片段的历史事务。
- 片段边界、命中、框选、缩放、复制、持久化、源文件及 PNG/SVG 导出共用新路径数据。
- 大批量裁切按需交给 Worker，结果必须与操作历史关联，不覆盖后续编辑或被撤销的状态。

## 验证
- 核心：稀疏采样、切三段、闭环首尾合并、弯曲笔迹、负尺寸、孔洞、边缘缺口、多个交叉擦痕、重复裁切、完全擦除、箭头头部、文件往返。
- 浏览器：切开后分别选中移动；一次撤销复原；缩放、保存恢复、源文件与 SVG/PNG 一致；保留现有 Custom Select 与单层边框回归。
- 运行单元、全量浏览器、严格类型与生产构建测试，测量典型与复杂裁切耗时。
