<h1 align="center">墨屿 · InkIsle</h1>

<p align="center">让想法，自由生长。</p>

墨屿是一款轻量、本地优先的无限白板，适合随手画图、记录灵感、整理思路和绘制草图。打开画布，用笔迹、图形、文字和便签，把零散的想法连接起来。

基于 TypeScript 和 Canvas 2D 构建，无前端运行时依赖，无需账号或后端服务。画板保存在本机，可导出为源文件、PNG 或 SVG。

## 功能

- **无限画布**：自由平移、1%–2000% 缩放、指针定位缩放与双指捏合，支持适应全部内容或选区。
- **自由书写**：手写笔压感、鼠标速度模拟粗细，支持等宽笔迹、虚线和不透明度调节。
- **图形与识别**：矩形、圆角矩形、椭圆、多边形、直线和单向/双向箭头；手绘轨迹可自动规整为三角形、矩形或椭圆。
- **文字与素材**：文字、便签和图片，可通过文件选择、拖放或剪贴板插入图片。
- **对象编辑**：单选、多选、完整包围框选、移动、缩放、旋转、锁定和层级调整，支持撤销、重做与复制粘贴。
- **局部橡皮**：擦除扫过的部分，擦断的笔迹和图形轮廓可拆成独立对象继续编辑。
- **调色与样式**：可编辑预设、HSV 色盘、HEX 输入、画布吸管，以及独立的描边、填充和填充开关。
- **本地画板库**：创建、命名、切换和管理多个画板，自动保存内容、视角与个人设置。
- **明暗主题**：响应式布局，支持小屏使用和自定义快捷键。

## 快速开始

开发环境需要 **Node.js 22.12+**。

```sh
git clone https://github.com/MCMR-JIM/inkisle.git
cd inkisle
npm ci
npm run dev
```

打开终端显示的地址，默认为 `http://localhost:5173`。

### 构建与部署

```sh
npm run build
npm run preview
```

构建产物位于 `dist/`，可部署到静态 HTTP(S) 服务器。

## 使用

从顶部工具栏选择画笔、图形、文字或便签即可开始创作。图形和直线按钮可展开子工具，绘制完成后保持当前工具，方便连续使用。

- 按住 **空格** 拖动以平移画布，使用 **Ctrl + 滚轮** 缩放。
- 按 **V** 切换选择工具，点击对象或拖出选框；框选需要完整包住对象。
- 按住 **Shift** 点击可多选，绘制或缩放时可约束比例。
- 双击文字或便签进行编辑，按 **Ctrl + Enter** 完成。
- 在左侧样式栏调整颜色、线宽和填充；选中对象后可调整其层级、锁定或删除。
- 点击右上角 **导出**，保存画板源文件或导出图片。

### 文件与数据

| 格式 | 用途 |
| --- | --- |
| `.inkisle` | 可继续编辑的画板源文件，支持导入和导出 |
| `.liubai` | 兼容导入的旧版画板文件 |
| PNG | 图片导出 |
| SVG | 矢量导出 |

选中对象时，PNG 和 SVG 可仅导出选区。画板文件可从菜单导入，也可直接拖入画布。

画板自动保存在浏览器的 IndexedDB 中，按站点和用户环境独立存储。使用 `.inkisle` 文件备份画板，或在不同浏览器和设备之间转移。

## 快捷键

| 操作 | 默认快捷键 |
| --- | --- |
| 选择 / 抓手 | `V` / `H` |
| 画笔 / 橡皮 | `P` / `E` |
| 矩形 / 椭圆 / 菱形 | `R` / `O` / `D` |
| 箭头 / 直线 | `A` / `L` |
| 文字 / 便签 / 图片 | `T` / `N` / `I` |
| 临时平移 | `空格 + 拖动` 或鼠标中键 |
| 下一个 / 上一个描边颜色 | `Tab` / `Shift + Tab` |
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Shift + Z` |
| 全选 / 复制一份 | `Ctrl + A` / `Ctrl + D` |
| 复制 / 剪切 / 粘贴 | `Ctrl + C` / `Ctrl + X` / `Ctrl + V` |
| 删除 / 微调 | `Delete` / 方向键 |
| 下移 / 上移一层 | `Ctrl + [` / `Ctrl + ]` |
| 置底 / 置顶 | `[` / `]` |
| 适应内容 / 100% | `Shift + 1` / `Shift + 0` |
| 导出源文件 | `Ctrl + S` |
| 快捷键设置 / 网格 | `?` / `G` |

macOS 使用 `Command` 对应 `Ctrl`。点击左下角键盘按钮可修改键位，设置保存在本机。

## Windows 桌面构建

原生 Win32 窗口通过 WebView2 加载白板，提供两种发行方式：

| 版本 | 运行方式 |
| --- | --- |
| 轻量版 | 使用系统安装的 WebView2 Runtime |
| 离线绿色版 | 随包携带固定版本 WebView2 Runtime |

```sh
npm run package:win:lite
npm run package:win:offline
```

构建工具、数据目录和运行说明见 [Windows 文档](docs/windows.md)。

## 开发

```text
src/
  core/       数据模型、几何、命中、识别、图层与文件格式
  engine/     Canvas 渲染、指针交互、几何 Worker 与导出
  storage/    IndexedDB、增量保存与快照 Worker
  ui/         工具栏、样式、调色板、快捷键与主题
desktop/
  windows/    Win32 桌面外壳
scripts/      Windows 构建、图标生成与原生验证
tests/        单元测试和浏览器测试
```
