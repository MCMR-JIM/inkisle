<h1 align="center">墨屿 · InkIsle</h1>

<p align="center">让想法，自由生长。</p>

墨屿是一款轻量、本地优先的无限白板，适合随手画图、记录灵感、整理思路和绘制草图。打开画布，用笔迹、图形、文字和便签，把零散的想法连接起来。

基于 TypeScript 和 Canvas 2D 构建，无前端运行时依赖，无需账号或后端服务。画板保存在本机，可导出为源文件、PNG 或 SVG。

当前版本 **0.2.0**，变更记录见 [更新日志](CHANGELOG.md)。

## 功能

- **无限画布**：自由平移、1%–2000% 缩放、指针定位缩放与双指捏合，支持适应全部内容或选区。
- **自由书写**：普通画笔与荧光笔，支持手写笔压感、鼠标速度模拟粗细、等宽笔迹、虚线和不透明度调节。
- **图形与识别**：矩形、圆角矩形、椭圆、多边形、直线和单向/双向箭头；手绘轨迹可自动规整为三角形、矩形或椭圆。
- **文字与素材**：文字、便签和图片，可通过文件选择、拖放或剪贴板插入图片。
- **对象编辑**：完整包围框选、多选移动、单对象缩放与旋转，支持锁定、层级调整、撤销、重做与复制粘贴。
- **嵌套组合**：对象与已有组合可继续组合，支持进入组合编辑子对象、逐层解组、对齐和等距分布。
- **局部橡皮**：擦除扫过的部分，擦断的笔迹和图形轮廓可拆成独立对象继续编辑；支持滚轮和滑块调整大小。
- **调色与样式**：可编辑预设、HSV 色盘、HEX 输入、画布吸管，以及独立的描边、填充和填充开关。
- **本地画板库**：创建、命名、搜索、排序和复制多个画板，自动保存内容、视角与个人设置；未命名的空画板不占用画板库。
- **图片导出**：PNG / SVG 可选整板或选区、透明或画板背景及留白，PNG 支持 1–4 倍分辨率。
- **明暗主题**：响应式布局，支持小屏使用和自定义快捷键。

## 快速开始

开发环境需要 **Node.js 22.12+**。

```sh
git clone https://github.com/MCMR-JIM/inkisle.git
cd inkisle
npm ci
npm run dev
```

打开终端显示的地址，默认为 `http://localhost:5173`。

### 构建与部署

```sh
npm run build
npm run preview
```

构建产物位于 `dist/`，可部署到静态 HTTP(S) 服务器。

## 使用

从工具栏选择画笔、图形、文字或便签即可开始创作。工具栏默认位于底部，可在右上角的工作区设置中切换到顶部。图形和直线按钮可展开子工具，快捷键选中子工具也会显示对应浮栏；绘制完成后保持当前工具，方便连续使用。

- 按住 **空格** 拖动以平移画布，使用 **Ctrl + 滚轮** 缩放。
- 点击右下角比例可选择 25%–400% 的预设，以当时的屏幕中心缩放；滚轮仍支持完整缩放范围。
- 按 **V** 切换选择工具，点击对象或拖出选框；框选需要完整包住对象。
- 按住 **Shift** 点击可多选，绘制或缩放时可约束比例。
- 双击文字或便签进行编辑，按 **Ctrl + Enter** 完成。
- 在左侧固定样式栏调整颜色、线宽和填充；右键菜单提供层级、复制、锁定和删除等操作。
- 选择画笔后，在浮栏中切换普通画笔 / 荧光笔或调整压感；荧光笔默认使用黄色、等宽和半透明笔迹。
- 选择橡皮后，用浮栏滑块或画布上的滚轮调节直径（4–120 屏幕像素）；向上滚放大，向下滚缩小，**Ctrl + 滚轮** 仍用于缩放画布。
- 点击右上角 **导出**，保存画板源文件或导出图片。

### 多选与组合

多选时，每个对象显示各自的选框，可一起移动；单独选中对象时可缩放或旋转。选区附近的浮栏提供组合、解组、对齐和等距分布。

按 **Ctrl + G** 组合、**Ctrl + Shift + G** 解开一层组合，最多支持 32 层嵌套。双击组合或选中后按 **Enter** 进入，随后可单选、Shift 多选或框选其内部对象；按 **Esc** 退出一层。**Ctrl + 点击** 可直接选中内部对象。组合结构会随撤销、重做、复制和源文件保存。

完整操作和共享 UI 组件约定见 [工作区说明](docs/workspace.md)。

### 文件与数据

| 格式 | 用途 |
| --- | --- |
| `.inkisle` | 可继续编辑的画板源文件，支持导入和导出 |
| `.liubai` | 兼容导入的旧版画板文件 |
| PNG | 图片导出 |
| SVG | 矢量导出 |

PNG 和 SVG 的导出设置可选择整张画板或选区、背景与 0–500 画布单位留白。PNG 显示实际输出尺寸，最大单边 8,192 像素、总计 1,600 万像素；SVG 保留矢量结构。源文件始终导出完整可编辑画板。画板文件可从菜单导入，也可直接拖入画布。

画板自动保存在浏览器的 IndexedDB 中，按站点和用户环境独立存储。使用 `.inkisle` 文件备份画板，或在不同浏览器和设备之间转移。

新画板在添加内容或命名后才保存。未命名画板清空后会从画板库移除，重做可恢复；已命名的空画板仍会保留。画板库支持按名称搜索、按最近编辑或名称排序、直接改名和独立复制。

## 快捷键

| 操作 | 默认快捷键 |
| --- | --- |
| 选择 / 抓手 | `V` / `H` |
| 画笔 / 橡皮 | `P` / `E` |
| 矩形 / 椭圆 / 菱形 | `R` / `O` / `D` |
| 箭头 / 直线 | `A` / `L` |
| 图形 / 线条分类浮栏 | `Shift + R` / `Shift + L` |
| 文字 / 便签 / 图片 | `T` / `N` / `I` |
| 临时平移 | `空格 + 拖动` 或鼠标中键 |
| 下一个 / 上一个描边颜色 | `Tab` / `Shift + Tab` |
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Shift + Z` |
| 全选 / 复制一份 | `Ctrl + A` / `Ctrl + D` |
| 复制 / 剪切 / 粘贴 | `Ctrl + C` / `Ctrl + X` / `Ctrl + V` |
| 组合 / 解组一层 | `Ctrl + G` / `Ctrl + Shift + G` |
| 进入 / 退出一层组合 | `Enter` / `Esc` |
| 删除 / 微调 | `Delete` / 方向键 |
| 下移 / 上移一层 | `Ctrl + [` / `Ctrl + ]` |
| 置底 / 置顶 | `[` / `]` |
| 适应内容 / 100% | `Shift + 1` / `Shift + 0` |
| 导出源文件 | `Ctrl + S` |
| 快捷键设置 / 网格 | `?` / `G` |

macOS 使用 `Command` 对应 `Ctrl`。点击左下角键盘按钮可修改键位，设置保存在本机。

## Windows 桌面构建

原生 Win32 窗口通过 WebView2 加载白板，提供两种发行方式：

| 版本 | 运行方式 |
| --- | --- |
| 轻量版 | 使用系统安装的 WebView2 Runtime |
| 离线绿色版 | 随包携带固定版本 WebView2 Runtime |

```sh
npm run package:win:lite
npm run package:win:offline
```

构建工具、数据目录和运行说明见 [Windows 文档](docs/windows.md)。

0.2.0 更新源码和版本标签，不提供新的 Windows 安装包或 GitHub Release；仓库保留的旧版包不包含本轮功能。

## 开发

```text
src/
  core/       数据模型、几何、命中、识别、图层与文件格式
  engine/     Canvas 渲染、指针交互、几何 Worker 与导出
  storage/    IndexedDB、增量保存与快照 Worker
  ui/         工具栏、样式、调色板、快捷键与主题
desktop/
  windows/    Win32 桌面外壳
scripts/      Windows 构建、图标生成与原生验证
tests/        单元测试和浏览器测试
```

### 版本维护

`package.json` 是 Web 界面版本号的来源，设置与快捷键帮助会自动显示该版本。更新版本时同步 `package-lock.json`、Windows 资源与 manifest 的版本，以及本页和更新日志。Windows 资源使用四段数字版本。

版本更新通过 PR 审核，合并采用 merge commit。版本标签使用 `v<版本号>`；标签与 GitHub Release 独立，创建标签不代表已发布 Release 或生成桌面包。本次 `v0.2.0` 指向版本更新 PR 的提交。
